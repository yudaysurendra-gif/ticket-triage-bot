# Ticket Triage Bot

A simple rule-based support ticket triage bot in Java (no external libraries).

It classifies each ticket by category, assigns a priority and team, drafts an auto-reply, and keeps open tickets in a priority queue.

## Run
```
cd src
javac TicketTriageBot.java
java TicketTriageBot
```
Requires Java 8+. Choose option 5 in the menu to load sample tickets.
